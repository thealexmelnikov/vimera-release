# VIMERA Light Console

Lighting desk for Windows and macOS: patch, cues, effects, timecode and a live
3D stage with real smoke. Light goes to the fixtures through the VIMERA DMX
Node.

**Website:** [vimera.lighting](https://vimera.lighting) · **Instagram:** [@vimera.lighting](https://www.instagram.com/vimera.lighting/)

This repository holds the installers only. Get them under
[Releases](https://github.com/thealexmelnikov/vimera-release/releases).

## English

### Download

| System | File |
|---|---|
| Windows 10 / 11, 64-bit | [Installer](https://github.com/thealexmelnikov/vimera-release/releases/latest) `Vimera-Setup-x.y.z.exe` |
| Windows, no install | Portable `Vimera-x.y.z-portable.exe`, in the same release |
| macOS 12 or later | Coming soon |

The desk is free, with no account and no time limit. To light real fixtures
you need a VIMERA DMX Node.

### First start on Windows

Windows may show **"Windows protected your PC"**. Click **More info**, then
**Run anyway**. You only do this once.

To check the file, compare its SHA-256 with the one in the release notes:

```
certutil -hashfile Vimera-Setup-1.0.7.exe SHA256
```

## Українська

### Завантаження

| Система | Файл |

| Windows 10 / 11, 64-біт | [Інсталятор](https://github.com/thealexmelnikov/vimera-release/releases/latest) `Vimera-Setup-x.y.z.exe` |

Windows може показати **«Windows protected your PC»**. Натисни **More info**,
потім **Run anyway**. Це треба зробити лише раз.

Щоб перевірити файл, порівняй його SHA-256 з тим, що в описі релізу:

```
certutil -hashfile Vimera-Setup-1.0.7.exe SHA256
```
